## 项目说明
1. 这是一个后端项目，使用Go语言编写。
2. 使用多函数结构模块化运行。
3.相对于main.go，main2.go是一个改进版本，增加了更多功能和优化：
     1/token的简单运用
     2/新增三个功能
     3/将内函数变量移到全局变量中，方便调用
4.使用ai帮助，并且此说明有些语句也是参考ai的，因为我没写过。

##运行方式
1.电脑安装好go语言环境
2.终端进入backend2
3.输入命令运行程序
```bash
go run main2.go
```
